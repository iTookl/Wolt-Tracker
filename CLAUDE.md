# Wolt Tracker

PWA для точного учёта смен и заработка курьера Wolt. Один пользователь, локальные данные, без бэкенда. Весь UI на русском, деньги в шекелях (₪), израильская локаль (`he-IL`).

## Команды
```bash
npm run dev      # vite dev-сервер
npm run build    # tsc (type-check) && vite build
npm run preview  # предпросмотр прод-сборки
```
Тестов нет. Перед коммитом полезно прогнать `npm run build` — он гоняет `tsc` со `strict`, `noUnusedLocals`, `noUnusedParameters`.

## Стек
React 18 + TypeScript (strict) + Vite + Tailwind + recharts. PWA через `vite-plugin-pwa` (`registerType: 'autoUpdate'`). Даты — `date-fns` (+ `ru` локаль). Без роутера: вкладки переключаются `useState` в `App.tsx`.

## Архитектура (слои сверху вниз)
- **`src/lib/storage.ts`** — изолированный репозиторий поверх `localStorage` (ключ `wolt-tracker:db`, `SCHEMA_VERSION = 2`; v1→v2 добавил `goals`). UI и хуки знают только про `storage`, не про localStorage напрямую — задел под IndexedDB. Все миграции схемы идут через `migrate()`.
- **`src/state/AppState.tsx`** — единый React-контекст: `shifts[]` + `planned[]`. Любое изменение немедленно персистится через `useEffect`. Доступ только через `useAppState()`.
- **Хуки-фасады** над состоянием:
  - `useActiveShift` — старт/пауза/завершение/отмена активной смены.
  - `useShifts` — завершённые смены (отсортированы), add/update/delete.
  - `usePlannedShifts` — плановые смены.
  - `useNow` — тикер текущего времени для живого таймера.
- **`src/lib/*`** — чистая доменная логика без React (см. ниже).
- **`src/screens/*`** — 4 вкладки (`TabBar`): **Смена** (`HomeScreen`), **История** (`HistoryScreen`), **План** (`PlanScreen` = месячная цель + недельная разбивка + календарь с авто-графиком под цель), **Аналитика** (`AnalyticsScreen` = под-вкладки Сводка `SummaryScreen` / Слоты `StatsScreen`). **`src/components/*`** — UI (модалки, графики, layout, `ui/` — Button/Card/Modal).

## Ключевые доменные инварианты (НЕ ломать)
1. **Точность времени (`lib/time.ts`)** — всё время считается из абсолютных timestamp'ов (`now − start − паузы`), а НЕ накоплением тиков `setInterval`. Блокировка экрана / фон / перезагрузка не должны влиять на точность. `activeMs()` — единый источник истины по чистому времени.
2. **Активная смена = элемент `shifts[]` со `status:'active'`.** Поэтому она сама восстанавливается из storage после перезагрузки. Не хранить активную смену отдельно.
3. **Паузы — массив `breaks[]`** интервалов `{start, end}`; открытая пауза имеет `end: null` (последний элемент). Помощники: `isPaused`, `currentBreakMs`, `breaksMs`.
4. **`endedAt` фиксируется в момент нажатия «Завершить»** (передаётся в `endShift`), а не при сохранении формы заработка — иначе время «доезжало» бы, пока вводят сумму.
5. **Авто-склейка смен за день** (`startShift`): если сегодня уже была завершённая смена, новый старт продолжает её новым периодом, а промежуток становится перерывом.
6. **Выплаты Wolt (`lib/payout.ts`)** — деньги приходят каждую **среду** (`paidOn = понедельник + 2`); период `(Пн, Пн]` = вторник…понедельник включительно. `payWeekLabel` — подпись по краям-понедельникам («8–15 июн.», как в выписке Wolt); `payWeekGoalLabel` — подпись по краям-вторникам (начало недели → вторник следующей недели, «23–30 июн», «30 июн – 7 июл»), используется на экране «Цель».
7. **Статистика (`lib/stats.ts`)** — только описательные средние по реальной истории, без прогнозов. Длинные смены делятся между слотами времени суток пропорционально календарным часам (`hourBuckets`). Порог «мало данных» `LOW_DATA_THRESHOLD = 3`.
8. **Цели (`lib/goal.ts`)** — **одна** цель: месячная (`Goals.monthlyTarget`, календарный месяц). Прогресс — **только по базе** (`shift.earnings`, без чаевых — в отличие от `stats.ts`, где база+чаевые). `weeklyTarget` — устаревшее поле, в UI не задаётся (недельная цифра выводится из месячной). Планировщик `buildMonthPlan` строит график под месячную цель на лету (**не персистится**): переменные часы `PLAN_MIN_HOURS..PLAN_MAX_HOURS` (3–9) — сильные дни недели длиннее, слабые короче; стратегия «максимум денег»; остаток раскидывается на доступные дни (не отработанные, без ручного плана, не выходные). Полуавто: ручной план (`PlannedShift`, `auto !== true`) и выходной (`Goals.offDays: string[]`) **фиксируют** день, остальные авто-дни пересчитываются. Также отдаёт недельную разбивку (Вс–Сб) план/факт и `perWeekNeed`. Легаси-функции `buildGoalPlan`/`autoPlansFromDays`/`payWeekGoalLabel` больше не используются в UI.

## Прочее
- **`lib/dataPort.ts`** — экспорт/импорт JSON (`ExportBundle`, версионирован) и CSV (с BOM для Excel). `parseImport` валидирует и бросает осмысленные ошибки.
- **`lib/money.ts`** — `formatMoney` / `formatRate`; целые числа без дробей, иначе 2 знака.
- **`lib/id.ts`** — `newId()` через `crypto.randomUUID()` с фолбэком.
- `StatsScreen` грузится лениво (`lazy`) — тянет recharts; lazy-обёртка теперь внутри `AnalyticsScreen` (под-вкладка «Слоты»).
- Онбординг (`WelcomeScreen`) показывается один раз, флаг `wolt-tracker:welcomeSeen` в localStorage.

## Конвенции
- Комментарии и строки UI — на русском, как в существующем коде.
- Доменную логику держать в `lib/` чистой (без React), UI — тонким.
- При добавлении полей в `Shift`/`PlannedShift` обновлять `migrate()` в storage.ts и маппинг в `parseImport`.
